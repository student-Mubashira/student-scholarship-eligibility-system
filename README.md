# Student Scholarship Eligibility System

A knowledge-based system that decides whether a student is ELIGIBLE,
NOT ELIGIBLE, PENDING (missing data) or INVALID INPUT.

## Features
- Knowledge representation: frames and semantic network
- Formal logic: First-Order Logic and Description Logic
- Horn clauses with forward and backward chaining
- Input validation (CGPA 0-4, attendance 0-100, income >= 0)
- Explanation trace for every decision

## Eligibility rules
- CGPA >= 3.00
- Attendance >= 75%
- Monthly family income <= PKR 100,000

## How to run
1. Open the notebook in Google Colab or Jupyter
2. Run all cells (Runtime -> Run all)
3. Libraries needed: matplotlib, networkx
